# Project_GenAi-Assistant_React_Js
Personal AI Assistant is a modern AI chatbot application built with React JS. It provides an interactive and responsive chat interface where users can ask questions and receive intelligent AI-generated responses in real time. The project integrates AI APIs like Gemini. This project is ideal for learning React concepts such as components
