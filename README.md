# Project GenAi-Assistant
Personal AI Assistant is a modern AI chatbot application built with React JS. It provides an interactive and responsive chat interface where users can ask questions and receive intelligent AI-generated responses in real time. The project integrates AI APIs like Gemini to create smooth and smart conversations with a clean user experience.

## About Project
This is an AI chatbot built with React JS.

## Features
- Real-time chat
- Gemini API integration
- Responsive UI

## Technologies Used
- React JS
- CSS
- Gemini API

## Installation
- npm install
- npm run dev
- 
## Implementation Details
* Built the user interface using React JS and reusable components.
* Used React Hooks (useState) to manage user input and chat messages.
* Integrated the Gemini API to get AI-generated responses in real time.
* Handled API calls and added loading and error messages for a better user experience.
* Improved the application by organizing components properly and updating the UI based on user interactions.
